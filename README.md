# 💪 FitAI – Fitness Tracking App with AI Chatbot

## 📌 Overview

FitAI is a full-stack fitness tracking application that helps users monitor workouts, track progress, and get AI-based fitness guidance through a chatbot.

---

## 🚀 Features

* 🏋️ Workout tracking (add, update, delete)
* 📊 Progress monitoring
* 🤖 AI chatbot for fitness advice
* 🔐 User authentication (JWT)
* 📱 Responsive UI

---

## 🛠️ Tech Stack

* Frontend: React.js
* Backend: Node.js, Express.js
* Database: MongoDB
* AI: OpenAI API (Chatbot)

---

## ⚙️ Installation

### 1. Clone the repo

```bash
git clone https://github.com/your-username/fitai.git
cd fitai
```

### 2. Install dependencies

```bash
cd server
npm install

cd ../client
npm install
```

### 3. Setup environment variables

Create a `.env` file in `/server`:

```
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret
OPENAI_API_KEY=your_api_key
```

### 4. Run the app

```bash
# backend
cd server
npm start

# frontend
cd client
npm start
```
